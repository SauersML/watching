# Figure assets

- `redon_fence.jpg`: Odilon Redon (1840–1916), charcoal drawing of an eye watching through a gap in a wooden fence. Public domain. `scripts/make_diagrams.py` recomposes it: the eye and crack are enlarged relative to the planks, and the eye is painted out for the unwatched condition.
- `robot.png`, `cat.png`, `owl.png`: painted for this project with [p5.brush](https://github.com/acamposuribe/p5.brush) (MIT, vendored in `scripts/vendor/`) by `scripts/draw_characters.py`, which renders `scripts/draw_characters.html` in headless Chrome.
