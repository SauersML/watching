# Fresh hook validation: required parity gate failed before scoring

The final 061r hook checkpoint was reloaded in a fresh process on the original retained RTX 6000 Ada pod, with Torch 2.10.0 / Transformers 5.18.0, BF16, the pinned Qwen3-8B base, and compiler caches force-disabled. No boundary recorder, fitting, or training was used. The checkpoint SHA256 is `13fd50dd05661322ea3bcef4b0ab936209eea665859a6ea7e100ba6f6ea8df9b` (step 1,024, fixed original head).

The required `LibraryInvocation(cut=None)` gate failed on the first absent-capture validation prompt: the compiled invocation with its hook registered but disabled did not reproduce the bare compiled model's full-sequence, full-vocabulary logits. Evaluation stopped before scoring any prompt pair. No fresh validation/test accuracy is available. This failure does not establish a detector null or an accuracy collapse.

The saved native BF16 counterexample has shape `[1, 96, 151936]`. Independent CPU reconstruction verifies 5,500,044 of 14,585,856 logits differ, with maximum absolute difference 1.03125. At the final token position, 146,012 vocabulary logits differ, maximum 0.3125. Both paths nevertheless select No (token 2753), and both have Yes/No log-odds −3.25 on this one prompt. Exact selected input IDs, masks, positions, checkpoint/head/state fingerprints and source hashes are retained.

The prior 061r whole-model measurements remain historical results from their earlier compiled runtime. This fresh process did not reach their accuracy measurement: it failed the stricter bare-model parity prerequisite. The two compiled paths also differ in ordinary call setup (the existing adapter explicitly passes the hidden-state flag); the counterexample alone does not isolate the cause of the numerical difference.

`raw/` preserves the compact evaluator outputs; the native full-sequence tensor pair is in the public release asset linked by `release.json`. `scientific_source/` is the exact immutable executed snapshot. After extracting the asset, run `PYTHONPATH=src python results/library-capture-training-061r-validation-hook/audit_failure.py` from the repository root to verify the independent review. There are zero scored final-position vector files because the gate failed first.

The retained interpreter target vanished across the earlier pod stop. The setup restored Python 3.12.15 persistently under `/workspace/uv-python`, retaining the existing pinned packages, model cache and checkpoint. The source venv recorded only the Python 3.12 minor version, so exact earlier interpreter patch parity is not independently established. The GPU type and retained pod match the original hook run. Setup failures and the live repair did not run an optimizer.
