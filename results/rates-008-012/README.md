# Earlier learning-rate and answer-row experiments

This archive contains baseline, final, and fresh-process scores for runs
008–012, plus their original manifests, data, optimizer diagnostics, and paired
analyses. These are gradient-based experiments preceding the native fixed-feature
least-squares fits. Training-path and ordinary-inference results must be read
separately; the later native-fit results do not retroactively establish success
for these runs.

`paired_changes.pdf` summarizes the archived comparisons. Each `analysis.json`
contains the prompt-paired calculation for its own arm. Large model checkpoints
and optimizer states are excluded.
