# Selected model: whole-model endpoint verification

The selected step-5,120 tail was reconstructed into the pinned Qwen3-8B model and evaluated through actual HF Trainer and compiled vLLM. On the locked fresh grid of 8 wordings × 8 contexts, **all 64 prompts receive the correct highest-probability vocabulary token in both conditions**, in each of two vLLM passes. No maximal-logit ties occur. Pass 0 paired Yes/No log-odds separation is 46.775 nats, with a descriptive 95% crossed wording/context bootstrap interval of [43.830, 49.662]. Mean full-vocabulary target NLL is 0.000000597 and mean correct-token probability is 99.999940%.

These are 64 particular prompts, not proof of perfect population accuracy. The all-correct empirical bootstrap accuracy interval collapses to [100%, 100%]; it supplies no unseen-error bound. The gap interval uses 5,000 paired crossed resamples, assumes exchangeable factor levels, and excludes seed/hardware and checkpoint-selection variability. There are only eight levels of each factor.

**What is detected:** HF execution versus compiled vLLM execution. The full final-position vocabulary vector is bit-identical between actual HF Trainer training_step and an HF eval/no_grad forward on all 64 fresh prompts and all 164 historical prompts. Consequently, this result does not identify gradient recording within HF. The plain HF forward includes a final-norm capture hook; its full-vector equality receipt is stored, while only the Trainer vector is archived.

**Repeat behavior:** the two fresh vLLM passes give the same correct answers, but 8,167,642 vocabulary scores differ, with maximum absolute difference 1.21875 nats. Historical passes also agree in answers while differing numerically. Evaluation enables prefix caching, whereas source capture disables it. Prefix-cache state is a possible explanation, not a demonstrated cause. The separately prepared ordinary-answer evaluator disables prefix caching.

On historical prompt sets, whole-model development is 93/96 pairs correct and historical nondevelopment is 64/68. These previously inspected banks differ from the locked fresh grid; report them separately. Cached development during training is another execution path, where the selected checkpoint scores 96/96.
